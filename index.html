Use the same task

Can you understand the dashboard without instructions?

  1. Open a candidate and identify what the dashboard says is happening now.
  2. Find the most important cost, risk, or recommended action.
  3. Check one other view, such as analysis or mobile, if available.
  4. Return the four short answers below. Five to ten minutes is enough.

This is a visual and usability comparison, not a code review. You may stop at any time. Please do not enter real Azure information.

Reply format

Short answers are enough.

1. Candidate __. I understood the current situation fastest because __.
2. Candidate __. I found the main cost, risk, or next action fastest because __.
3. Candidate __, because __.
4. Candidate __, __ view: __ made __ harder.

You can use this format in the GitHub form. One short sentence per answer is enough. A screenshot is optional and should contain no personal or confidential data.

Optional detail

Make your feedback easier to act on.

  1. Name the candidate and view, such as Candidate C, mobile.
  2. Describe what you saw, not what you think the code does.
  3. Say what you would change or what blocked you.
  4. Mention useful context, such as a phone screen, low vision, or dark-room viewing.

Useful example: Candidate C, mobile view: the navigation uses most of the screen and the dashboard text becomes too narrow to read.
